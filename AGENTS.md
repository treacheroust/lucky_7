# Repository guidance

This is a public repository published as a GitHub Pages site. Treat every committed file as publicly accessible.

- Only commit content that is intentionally approved for public release.
- Never commit or push credentials, secrets, API tokens, personal information, order or customer data, private exports, or machine-specific paths.
- Before every commit or push, review `git status` and the complete staged diff for sensitive or unintended content.
- Keep the site dependency-free and compatible with static GitHub Pages hosting unless the user explicitly approves a different approach.
